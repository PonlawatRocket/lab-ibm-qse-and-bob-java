Why the Java Structure is Shallow

All Java source files live directly under src/main/java/demo/ with package package demo;


This shallow structure means IBM QSE can map every finding directly to a single flat list of class names — no package hierarchy to navigate. Each cryptographic operation lives in a dedicated service class with a dedicated method, keeping crypto assets individually addressable for IBM Bob's remediation step.
